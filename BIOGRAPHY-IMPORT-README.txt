PINK TRIANGLE PORTRAITS — BIOGRAPHY IMPORT

This ZIP contains the complete updated GitHub website, including 61 biography pages and 68 artwork entries.

HOW TO INSTALL
1. Back up the current GitHub repository.
2. Upload/replace the files and folders from this ZIP at the repository root (not inside an extra parent folder).
3. Commit to GitHub and wait for the Cloudflare Pages staging deployment.
4. Check /portraits/ and several /people/<person-id>/ pages before connecting the live domain.

IMAGES
The portrait images are in assets/images/portraits/. Every JPG has a maximum dimension of 800 pixels. Original full-resolution images are NOT included. Images can be reused by selecting their paths in Pages CMS.

IMPORTANT: Pages CMS itself does NOT automatically resize future uploads. Before adding any NEW artwork to the public repo, resize it to 800 pixels or less. Existing imports are already resized. Public image downloads cannot be technically disabled.
